Advanced Settings
  • Monitor Width / View Distance: set PD estimation scaling. Monitor Width is saved in this browser after first setup.
  • Start PD: debug-only value used as the initial PD estimate.
  • Round Seconds: controls the round timer (default 20s). Timeout beeps and scores -1.
  • Field Shape: changes only the outer stereogram field between `Circle` and `Square`.
  • Debug Shortcuts: [ or - / _ for -1; ] or = / + for +1. Works in fullscreen.
  • Vertical Mode Mapping: flips `Vergence Up` / `Vergence Down` polarity if clinical testing suggests the opposite convention.
  • Eye Split: read-only rendering split shown for reference, with `H` or `V` axis tags.

  • Arrow Keys = choose side (up/right/down/left)
  • You will see overlapping red/cyan dot fields. With fusion, a single target appears in depth from binocular disparity (not a drawn outline).
  • Space = cannot see target, score -1 and refresh
  • Two vigilance dots sit above and below the field; each is visible to one eye only. If either fades, that eye is suppressing: press S (score unchanged, demand drops, new stereogram).
  • P = pause/resume session. Exiting fullscreen with Esc pauses automatically.
  • Switching tabs or windows auto-pauses the session so the timers do not keep running in the background.
  • Core Settings (in order): Vergence Mode, Visual Preset, Session Target, and Session Minutes define the session profile.
  • Three correct answers in a row increase PD; wrong answers, timeout, and Space reduce PD.
